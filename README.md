# Planner API — Node.js (legado)

Este repositório contém a versão original do backend do **Weekly Planner** desenvolvida em **Node.js + Express + MongoDB**.

## Tecnologias

- Node.js
- Express
- MongoDB (Mongoose)
- JSON Web Token (JWT)
- Nodemailer

## Continuidade do Projeto

Este repositório é mantido como referência de portfólio.

A versão atual e oficial do backend foi reescrita em **Python/FastAPI** e está disponível em:
👉 [https://github.com/soniamarasa/planner-api-python](https://github.com/soniamarasa/planner-api-python)

## Como executar

```bash
npm install
npm start
```
